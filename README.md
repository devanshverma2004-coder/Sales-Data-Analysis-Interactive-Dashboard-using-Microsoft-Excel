# Sales-Data-Analysis-Interactive-Dashboard-using-Microsoft-Excel
Interactive Excel Sales Dashboard analyzing 2,707 records across 17 countries using Pivot Tables, Pivot Charts, formulas, and Slicers to track revenue, profitability, and sales performance.
# Excel Sales Performance & Profitability Dashboard

## Project Overview
This project is an interactive Sales Performance and Profitability Dashboard built using Microsoft Excel. It analyzes 2,707 sales records across 17 countries to identify business trends, evaluate profitability, and generate meaningful insights from sales data.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Formulas
- Slicers
- Data Cleaning & Data Analysis
- Data Visualization

## Key Features
- Interactive sales dashboard with slicers.
- Revenue, COGS, Gross Profit, and Gross Margin analysis.
- Monthly and quarterly sales performance.
- Country-wise sales analysis.
- Product category performance comparison.
- Sales channel and customer type analysis.
- Dynamic charts and visual reports.

## Key Performance Indicators (KPIs)
| Metric | Result |
|---|---:|
| Total Revenue | 645,223.18 |
| Gross Profit | 296,384.25 |
| Gross Margin | 45.94% |
| Units Sold | 6,698 |
| Total Records | 2,707 |

## Key Business Insights
- Camping generated the highest revenue among product categories.
- Online Store was the top-performing sales channel.
- June recorded the highest monthly revenue.
- The dashboard helps compare sales performance across countries, categories, and channels.

## Excel Skills Demonstrated
- Data organization and cleaning
- Calculated columns using Excel formulas
- Pivot Table creation and analysis
- Pivot Chart visualization
- Interactive dashboard development using Slicers
- Business insights and KPI reporting

## Project Objective
The main objective of this project was to convert raw sales data into an interactive dashboard that makes business performance easier to understand and supports data-driven decision-making.
